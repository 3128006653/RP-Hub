RP-Hub · GitHub Pages 部署版
============================

用途：fork 到自己的 GitHub 账号，部署成在线网址，手机/电脑浏览器直接打开。
      Vue 等核心依赖已放在 assets/js/vendor/，与页面同源，不再经过 unpkg.com。

一、部署（电脑浏览器做一次，约 5 分钟；之后手机只管用）
  1. 打开 https://github.com/STA1N156/RP-Hub ，点右上角 Fork → Create fork。
  2. 把本包内全部文件推送到 fork 仓库的 main 分支根目录。
     方式 A（命令行，在本包解压目录执行）：
         git init
         git remote add origin https://github.com/你的用户名/RP-Hub.git
         git add -A
         git commit -m "fix: localize vendor libs to avoid white screen"
         git push -u origin main --force
     方式 B（不用命令行）：在 fork 仓库页点 Add file → Upload files，
         把解压后的全部文件拖进去（约 30 个，同名文件会覆盖），Commit changes。
  3. 仓库 Settings → Pages → Build and deployment → Source 选 Deploy from a branch
     → Branch 选 main / (root) → Save。等 1~2 分钟。
  4. 访问 https://你的用户名.github.io/RP-Hub/ 验证。

二、手机使用
  用手机浏览器打开上面那个网址，菜单里选「添加到主屏幕」，之后像 App 一样点开即可。
  建议固定用同一个浏览器入口（不要一会儿 Safari、一会儿主屏快捷方式），
  因为浏览器本地存储是按站点/容器隔离的，换入口会看起来像"数据没了"。

三、把旧数据搬过来（重要，趁原站还能打开时做）
  浏览器 localStorage 按域名隔离，新网址看不到 sta1n156.github.io 上存的角色卡和聊天记录。
  最省事的是用项目自带的「备份与转移」功能，手机也能操作：
  1. 在原站 https://sta1n156.github.io/RP-Hub/ 打开设置 → 备份与转移 → 上传备份，
     记下生成的密钥（15 天有效，单次最多 1GB，密钥等于取件码请勿外传）。
  2. 在自己的 Pages 网址里打开 备份与转移 → 下载备份 → 输入密钥 → 恢复。
  3. 完成后页面自动刷新，角色卡和聊天记录就回来了。
  备用方案（需要控制台，手机不便）：原站控制台 copy(JSON.stringify(localStorage))，
     新站控制台 Object.keys(d).forEach(k => localStorage.setItem(k, d[k])) 后刷新。
  导出成功前，不要清理浏览器数据。

四、本包改了什么
  - Vue 3.5.13 / marked / DOMPurify / SortableJS / localforage / daisyUI
    放进 assets/js/vendor/，index.html、character/index.html、novel/index.html 改为同源引用。
  - 三个页面末尾加了兜底：核心库未载入时显示红色错误提示，而不是一片白屏。
    （手机浏览器看不到 DevTools，这条尤其有用）
  - tailwind-theme.js 加了防御：Play CDN 未载入时不再抛错阻断脚本。

五、仍会联网的部分（都不会导致白屏）
  - cdn.tailwindcss.com ：运行时生成样式。加载失败只是样式缺失，不影响功能启动。
    作者原版就依赖它；本环境无法取得可分发副本，故保留原地址。
  - Google Fonts：字体，失败自动回退系统字体。
  - AI 接口 / 云备份 / 更新检查 / 论坛链接：业务功能本身，按你自己在设置里填的地址决定。
    手机上使用 AI 对话，需要服务商支持浏览器直连的 CORS 与 Chat Completions 行为。

六、维护提示
  fork 仓库后，index.html 里的 <meta name="rphub-update-api"> 仍指向作者的服务，
  可能收到上游更新提示；如不需要，改成你自己的地址或关闭更新检查即可。
